# Security Policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

DriftJax is a scientific simulation library with no network surface, but
dependency or packaging issues can still matter. Please report suspected
vulnerabilities via a private GitHub Security Advisory on this repository
rather than a public issue. Include:

- Affected version(s) and how the issue was found
- Steps to reproduce or a proof of concept
- Your assessment of impact

We aim to acknowledge reports within 7 days and to publish a fix or a
mitigation statement as soon as one is validated.

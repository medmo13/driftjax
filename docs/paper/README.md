# DriftJax paper sources

LaTeX sources for the DriftJax methods paper (CPC Program Library submission)
and its supplementary material. All `\input` / `\bibliography` references are
bare filenames and the graphics path is `records/`, so everything in this
directory builds in place with no path edits.

| File | Role |
|------|------|
| `DriftJax_content.tex` | Scientific body (shared by both wrappers) |
| `DriftJax_abstract.tex` | Abstract (shared) |
| `DriftJax_shared.tex` | Preamble, macros, graphics path (shared) |
| `DriftJax_paper.tex` | Standard article wrapper |
| `DriftJax_CAS.tex` | Elsevier CAS wrapper |
| `DriftJax_supplementary.tex` | Supplementary material (standalone) |
| `DriftJax_paper.md` | Markdown source (pandoc pipeline, see below) |
| `provenance_table.tex` | Standalone figure/claim provenance record |
| `cas-refs.bib` | Bibliography |
| `cas-sc.cls`, `cas-common.sty`, `stfloats.sty`, `cas-model2-names.bst` | Journal class/style files |
| `build_latex.py` | Regenerates `DriftJax_paper.tex` from the Markdown source |
| `paper.template.tex` | Pandoc LaTeX template (regenerated by `build_latex.py`) |
| `records/` | Paper figures + JSON sidecars + logs (regenerated from `examples/`, committed) |

## Build

```bash
cd docs/paper
pdflatex DriftJax_paper && bibtex DriftJax_paper && pdflatex DriftJax_paper && pdflatex DriftJax_paper
pdflatex DriftJax_supplementary && bibtex DriftJax_supplementary && pdflatex DriftJax_supplementary && pdflatex DriftJax_supplementary
```

To regenerate the article body from Markdown (requires pandoc):

```bash
python build_latex.py
```

Figures are reproduced by running the example gallery from the repository root
and copying the PNGs (+ JSON sidecars, logs) into `records/`.
